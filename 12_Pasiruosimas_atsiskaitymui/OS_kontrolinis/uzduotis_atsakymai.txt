11. Suteikite vartotojui student (arba pradiniam vartotojui) teisę
    vykdyti (execute) proc.zip.  (1 t.)
---------------------------------------------------------------------
   Variantas A – per "kiti" / via "others" (paprasčiausias):
   $ chmod o+x ~/Desktop/proc.zip
   Variantas B – tiksliai tam vartotojui (ACL) / exactly that user:
   $ setfacl -m u:student:x ~/Desktop/proc.zip
   $ getfacl ~/Desktop/proc.zip
   Variantas C – savininkas student / make student the owner:
   $ sudo chown student ~/Desktop/proc.zip && chmod u+x ~/Desktop/proc.zip
   $ ls -l ~/Desktop/proc.zip

   LT: o+x – kitiems (ne savininkui, ne grupei) pridėti x. setfacl –
       teisė konkrečiam vartotojui. Kad student pasiektų failą, jis turi
       galėti įeiti į /home/laikymas ir Desktop (chmod o+x katalogams).
   EN: o+x – add execute for others. setfacl – permission for a specific
       user. For student to reach the file they must be able to enter
       /home/laikymas and Desktop (chmod o+x on those dirs).

12. Kokias teises turite failui /bin/ls.  (1 t.)
---------------------------------------------------------------------
   $ ls -l /bin/ls              # -rwxr-xr-x 1 root root ... → kiti: r-x
   $ stat /bin/ls
   $ stat -c "%A %U %G" /bin/ls
   $ getfacl /bin/ls

   LT: esate "kiti" (ne root, ne grupė root) → r-x: skaityti ir vykdyti.
   EN: you are "others" → r-x: read and execute.

13. Kataloge /home suraskite visus failus, susijusius su "mozilla". (1 t.)
---------------------------------------------------------------------
   $ find /home -iname "*mozilla*" 2>/dev/null
   $ sudo find /home -iname "*mozilla*"          # ir kitų vartotojų / other users too
   $ grep -rl mozilla /home 2>/dev/null          # failai, kurių viduje yra žodis / by content

   LT: -iname nepaiso raidžių dydžio; 2>/dev/null slepia Permission denied.
   EN: -iname is case-insensitive; 2>/dev/null hides Permission denied.

14. Ar sistemoje yra "zombinių" procesų.  (1 t.)
---------------------------------------------------------------------
   $ ps aux | awk '$8 ~ /Z/'
   $ ps -eo pid,ppid,stat,cmd | grep -w Z
   $ ps aux | grep -w Z | grep -v grep
   $ top            # antraštėje: "Tasks: ... 0 zombie" / header shows zombie count

   LT: zombie (Z, <defunct>) – baigęs darbą procesas, kurio tėvas dar
       neperskaitė rezultato. Šalinamas nužudžius tėvą (kill PPID).
   EN: zombie (Z, <defunct>) – a finished process whose parent has not
       yet collected its exit status. Removed by killing the parent.

15. Scenarijus, kuris suskaičiuoja visus failus namų kataloge (su
    pakatalogiais) ir išveda skaičių.  (2 t.)
---------------------------------------------------------------------
   $ nano ~/count.sh
   ------------------------------ count.sh ---------------------------
   #!/bin/bash
   # Suskaičiuoja visus failus namų kataloge / counts all files in home
   KIEK=$(find "$HOME" -type f 2>/dev/null | wc -l)
   echo "Namų kataloge $HOME yra $KIEK failų"
   -------------------------------------------------------------------
   $ chmod +x ~/count.sh
   $ ~/count.sh

   LT: find -type f – tik failai (ne katalogai); wc -l skaičiuoja eilutes;
       $(...) įrašo rezultatą į kintamąjį. Su katalogais: find "$HOME" | wc -l
   EN: find -type f – regular files only; wc -l counts lines; $(...)
       captures output into a variable. Including dirs: find "$HOME" | wc -l

17. Per SSH iš Host sukurkite Apache tinklalapį, pasiekiamą per domeną;
    turinys "Sveiki atvykę į mano puslapį."  (3 t.)
---------------------------------------------------------------------
   (viskas per SSH sesiją / all inside the SSH session)
   $ sudo apt install -y apache2
   $ sudo systemctl enable --now apache2
   $ sudo mkdir -p /var/www/mano
   $ echo '<!DOCTYPE html><html><head><meta charset="UTF-8"><title>Mano puslapis</title></head><body><h1>Sveiki atvykę į mano puslapį.</h1></body></html>' | sudo tee /var/www/mano/index.html
   $ sudo chown -R www-data:www-data /var/www/mano
   $ sudo tee /etc/apache2/sites-available/mano.conf > /dev/null <<'CONF'
   <VirtualHost *:80>
       ServerName mano.local
       ServerAlias www.mano.local
       DocumentRoot /var/www/mano
       <Directory /var/www/mano>
           Require all granted
       </Directory>
   </VirtualHost>
   CONF
   $ sudo a2ensite mano.conf
   $ sudo apachectl configtest
   $ sudo systemctl reload apache2
   $ curl -H "Host: mano.local" http://localhost

   Domenas / domain (pasirinkite vieną / pick one):
   a) Vietinis: Host OS hosts faile (Windows: C:\Windows\System32\drivers\etc\hosts,
      atidaryti Notepad kaip administratorius) pridėti:
         <Ubuntu_IP>  mano.local www.mano.local
      Ubuntu: echo "127.0.0.1 mano.local" | sudo tee -a /etc/hosts
   b) Tikras: noip.com → hostname (pvz. mano.ddns.net) → ServerName
      mano.ddns.net → maršrutizatoriuje port forward 80.
   Patikrinti naršyklėje / check in browser: http://mano.local
